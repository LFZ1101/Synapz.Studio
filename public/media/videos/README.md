# Vídeos institucionais

## Studio — bloco “O que é a SYNAPZ”

Coloque o vídeo institucional neste caminho (nome exato):

```
public/media/videos/studio-synapz.mp4
```

### Formato esperado
- **1920×1080 (16:9 / landscape)**
- MP4 (H.264 + AAC)
- Autoplay no site (muted + loop)

### No GitHub

1. Abra a pasta:
   https://github.com/LFZ1101/Synapz.Studio/tree/main/public/media/videos
2. Clique em **Add file → Upload files** (ou substitua o arquivo existente)
3. Envie como `studio-synapz.mp4`
4. Commit na branch `main`

Depois do upload, o vídeo aparece automaticamente no retângulo 16:9 da página `/studio`.
